# Loan-Approval-Prediction-using-ML

The dataset was taken from https://www.kaggle.com/datasets/architsharma01/loan-approval-prediction-dataset

In this project ,I have made a machine learning model which predicts if a customer should be given loan or not based on its features and past loan approval history of all the customers in the dataset.

In this project I performed following things - :
* Imported required libraries like pandas,numpy,maplotlib,seaborn,scikit-learn,scipy
* Load the data
* Cleaned the dataset
* Performed Exploratory data analysis
* Performed Featured Engineering
* Made Base ML model like KNN,SVM and Decision to compare their accuracies
* Selected the best model among them to solve the problem
* Perfomed GridSearch (Hyperparameter Tuning)
* Built the best model
* Compared accuracy_score,recall_score ,precision_score and f1_score and accordingly modified the model.
* Built the final model to make predictions on real data.
* Concluded the project.
